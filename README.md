# ربات یادآوری نوبت مشهد

این پروژه هر ۱۵ دقیقه یک پیام یادآوری در تلگرام می‌فرستد و لینک فرم رسمی را ارائه می‌کند.
این نسخه **ظرفیت سایت را خودکار تشخیص نمی‌دهد** و کپچا را دور نمی‌زند یا فرم را ارسال نمی‌کند.

## راه‌اندازی با گوشی

1. فایل‌های این پوشه را در مخزن خصوصی GitHub خود بارگذاری کنید.
2. در مخزن به مسیر `Settings` → `Secrets and variables` → `Actions` بروید.
3. دو Repository secret بسازید:
   - `TELEGRAM_BOT_TOKEN` = توکن جدید ربات (فقط اینجا وارد شود؛ آن را در چت یا فایل‌ها ننویسید)
   - `TELEGRAM_CHAT_ID` = شناسه عددی تلگرام خودتان
4. در تب `Actions` گردش‌کار `Telegram appointment reminder` را فعال کنید، اگر GitHub درخواست فعال‌سازی کرد.
5. برای آزمایش، از مسیر `Actions` → `Telegram appointment reminder` → `Run workflow` آن را دستی اجرا کنید.

## پیدا کردن CHAT_ID

1. در تلگرام وارد ربات خودتان شوید و `/start` بفرستید.
2. در تلگرام به ربات `@userinfobot` پیام بدهید؛ شناسه عددی شما را نشان می‌دهد.
3. همان عدد را به عنوان مقدار `TELEGRAM_CHAT_ID` در GitHub Secret قرار دهید.

## نکته زمان‌بندی

GitHub Actions ممکن است اجرای زمان‌بندی‌شده را چند دقیقه دیرتر انجام دهد؛ بنابراین پیام دقیقاً سرِ هر ۱۵ دقیقه تضمین نمی‌شود.
